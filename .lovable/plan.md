# Ambitious AI ideas for MCQsAI

Each idea builds on what MCQsAI already has: the question bank, mock tests, exam pages and AI Coach. Pick one idea and I'll write a detailed build plan for it.

## 1. Voice AI Tutor in Urdu, Sindhi and English
Students ask questions out loud and hear the answer spoken back, in their own language. The tutor explains MCQs step by step, using only approved questions and syllabus content.

## 2. Photo-to-Practice
A student photographs a textbook page or a past paper. The AI reads it, finds the topic, and starts a practice test from questions already approved in the bank. It only creates new questions if the bank has none.

## 3. Adaptive "Exam Twin"
Builds a personal copy of a real exam (MDCAT, STS, NTHP, FPSC) for each student. The difficulty adjusts as they answer. At the end it estimates how ready they are for each section, but only for tests whose official pattern is already stored in the database.

## 4. AI Study Planner tied to real deadlines
Uses the verified exam dates on the exam pages to build a day-by-day plan up to test day. Sessions are spaced so weak topics come back for review, and the plan changes after each test the student takes.

## 5. Explain-My-Mistake video cards
After a test, the student gets short narrated cards with animated diagrams that explain each wrong answer. Cards are made once per question and saved, so the AI cost is paid only once.

## 6. Live Group Battle Mode
Friends from a WhatsApp group join one room and answer the same MCQs at the same time. A leaderboard updates live, and an AI host comments on the game. This makes good shareable content for growing the audience.

## 7. Admin "Content Agent"
An AI helper that watches the Content Health dashboard and finds topics with few questions. It drafts new MCQs from the uploaded official PDFs and lines them up for admin approval. It never publishes anything on its own.

## 8. Official Notice Reader
An admin uploads an official notice as a PDF or poster image. The AI pulls out the dates, fees and eligibility into the exam page fields and highlights anything it is unsure about. The admin checks it before anything goes live.

## Guardrails that apply to every idea
- Use free Gemini keys first, with the daily cap on paid calls kept in place.
- Save AI results once and reuse them, so the same content is never generated twice.
- Never invent facts. Unknown details show "Not yet announced."
- Admin approval before any new content is published.
