
- Indexable /p/* slugs for the sitemap and prerender list are derived from the real quality gate (scripts/prog-seo-gate.mjs), never hand-copied — so a noindex page can never be listed in the sitemap.
- Exam page facts live in the exam_pages table; code props are fallback, a build-time snapshot (scripts/fetch-exam-facts.mjs) feeds prerender, and /exams/* sitemap entries come only from examPassesGate() — so admins edit facts without code changes and the sitemap never drifts from the gate.

- Legacy /subject/<uuid> and /subject-content/<uuid> heads are written at build time by scripts/inject-meta.mjs (canonical → indexable board subject hub, else self), and GlobalCanonical skips those paths — so Google never sees them as homepage duplicates and the browser does not override the build canonical.
- Board topic internal links (prev/next, sibling window, hub link) come only from src/lib/topicLinkGraph.js over src/generated/topicOrder.json (indexable topics, curriculum order, built by scripts/build-topic-order.mjs) — so static HTML and the client page always emit identical, deterministic links.
- Build scripts must page every Supabase table read with .range() (1000-row cap) and fail the build if an indexable topic path has no topic_id — truncated maps silently stripped static content from 158 pages.
- STHP apply/test date wording on the mock-test page (client + prerender) comes only from src/lib/sthpStatus.js over the exam_pages "sthp" snapshot — so admins change dates without code edits and wording auto-switches after test day.
- Mock-test STS/NTHP membership (isStsTest/isNthpTest) and per-round open/closed status come only from src/lib/programStatus.js, used by the app and build scripts — so IBA Karachi NTHP never links to or lists STS tests, and each round closes on its own deadline.
- Job/scholarship expiry (noindex + sitemap removal) comes only from src/lib/opportunityExpiry.js, used by OpportunityDetail, inject-meta and generate-sitemaps — so browser HTML, prerendered HTML and sitemaps never disagree. Sitemap generator keeps the previous file when a DB read fails, so an outage never blanks a sitemap.
- Blog indexability (noindex + blog.xml removal) comes only from src/lib/blogIndexability.js, used by BlogPost, inject-meta and generate-sitemaps — so browser HTML, prerendered HTML and blog.xml never disagree.
- Third-party startup libraries use the shared inline load-then-delay idle scheduler in index.html, with a bounded timer fallback — so user input never initiates these downloads.
- Growth lifecycle hooks resolve only public test metadata and deduplicate lifecycle signals; never send session IDs or user-provided session names to analytics or result shares.
- Join Alerts uses a dedicated system_settings key, fetched into a build-time snapshot for static anchors and refreshed client-side; missing values stay hidden without a default.
- Free practice PDF landing pages (/pdf/:slug) come only from src/lib/practicePdfs.js (pages, hub/mock-test boxes, exams.xml entries) — so a new exam PDF is added by data only; PDFs live in public/downloads/ on the apex domain and never enter a sitemap.
- Mock-test question quality is judged only by the quality-gate edge function into question_quality_reviews (rules in supabase/functions/_shared/qualityChecks.ts); it never edits live questions, uses free Gemini keys only, and is a no-op when system_settings.quality_mode is off — so it is fully reversible and cannot spend paid credits.
- Every Gemini text call goes through callAIWithAutoSwitch with a job group; background groups (quality_gate, auto_fill, admin_bulk) are checked against system_settings.ai_free_budget (supabase/functions/_shared/freeBudget.ts), skip keys parked in free_key_health, never use the paid gateway and never retry after an all-keys 429 — so background jobs cannot starve learners or spend credits.
- Featured Exams cards (homepage + /exams) come only from the featured_cards table via src/lib/featuredCards.js, with a build-time snapshot (scripts/fetch-featured-cards.mjs) for static HTML and a live refresh after paint — so admins edit cards without code and expired cards hide automatically in Pakistan time.
- Deterministic content-safety rules live only in src/lib/contentSafety.js; supabase/functions/_shared/contentSafety.js is a byte-identical copy (test enforces) — so the PDF Builder and Quality Gate can never judge a question differently.
- Quality Gate saves no-AI results before any AI call and caps each run (10 questions, 2 AI calls, 60 s, 5-min lease) — so an exhausted free quota or a killed worker can never stall progress or leave a fake "running" status.
- Optional widgets load via safeImport (src/lib/chunkErrors.js) and render nothing on failure; routes use lazyWithReload; GlobalErrorBoundary reloads once (sessionStorage guard) on missing chunks — so a publish never crashes a page.
- `?start=1` mock-test auto-start comes only from src/lib/autoStart.js (no bots/prerender) — so the intro page stays indexable.
- Mock-test page titles from job_tests.seo_title go through src/lib/mockTestTitle.js (keep a trailing "| MCQsAI", else add it only if ≤65 chars), used by MockTestDetail and inject-meta — so browser and prerendered titles never differ.
